# HC3-Chinese 误报测试

规则的证据标签全部来自 lieflat-less-ai-tone 的语料，那份语料不公开，社区里几个中文去 AI 味项目的基线也都出自它。这里用一份公开、来源不同的数据集，看检测器在真人文本上会报出多少命中。

## 数据和口径

- 数据：[HC3-Chinese](https://huggingface.co/datasets/Hello-SimpleAI/HC3-Chinese) 的 `all.jsonl`，同一批问题的人类回答（百科、开放问答、金融、法律、医疗、心理）和 ChatGPT 回答，2022 年底采集
- 只取 ≥200 汉字的回答
- "超线"：`stop-slop detect --json` 里该项 `flagged` 为 true；只统计 A / B / F 三级
- 检测器版本 1.4.0（2026-11-09）

复现：

```bash
curl -L -o all.jsonl https://huggingface.co/datasets/Hello-SimpleAI/HC3-Chinese/resolve/main/all.jsonl
python3 -I tests/hc3/run.py all.jsonl cli/target/release/stop-slop
```

## 怎么读

1. **单篇"有命中"不说明任何事。** 真人回答里 82.4% 至少有一项超线，GPT-3.5 是 84.4%，两边几乎一样。检测器是定位工具，报告的是"这里可以看一眼"，不是"这篇是 AI 写的"。这也是 detect 报告里"误报参考"那一行的来源：本项在真人回答里超线比例 ≥5% 时，会附上这个比例。
2. **GPT-3.5 明显更多的**：段首连接词当路标（7.3×）、八股连接词（6.6×）、名词化（2.6×）、连续三句同构（2.0×）、相邻两句同构（1.6×）。名词化在 lieflat 的配对复测里没有差异（SKILL.md 标的是【可读性】），这里有差异，说明它可能跟模型代际有关，标签暂不改。
3. **真人反而更多的**：程度副词（人类 22.0% vs 12.3%）、二元对立（4.9% vs 0.8%）、分号、破折号、感叹号、省略号、过长前置定语。二元对立在 lieflat 里是最强的信号（GPT、Opus 配对复测都偏高），在 GPT-3.5 上却反过来。这跟 tropes.fyi 把"不是 X 而是 Y"标成"上升中"的痕迹对得上：它是新一代模型的习惯，不是所有 AI 的习惯。标点也一样：破折号在 Claude、DeepSeek 上偏多，GPT 系少。

## 局限

- ChatGPT 一侧是 2022 年的 GPT-3.5，不是现在常用的模型。这份结果只能说明真人文本里各项的触发率（误报这一侧），不能用来否定 lieflat 对新模型的测量
- 人类回答主要是问答社区和百科的风格，口语化、短，跟公众号长文、技术文档不是一类
- 阈值没有在这份数据上调过，所以误报率没有被调低；反过来，也没有为这类文本专门调高
